SEZA POS 1.2.1 — Admin Support + Whole-App Language Update

INSTALL:
1. Copy this pos-sezapos folder into F:\ and choose Replace files in destination.
2. Open F:\pos-sezapos in VS Code.
3. Run:
   npm install --legacy-peer-deps
   npm run build
   npx cap sync android
4. After the build succeeds:
   git add .
   git commit -m "SEZA POS 1.2.1 support and language reliability"
   git pull --rebase origin main
   git push origin main

This patch contains changed files only. It does not include or replace .env files.
