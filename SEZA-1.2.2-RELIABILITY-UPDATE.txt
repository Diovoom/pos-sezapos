SEZA POS 1.2.2 — Reliability, Offline, Support & Screen Sharing
Android build: 5

This update focuses on production reliability across the Android POS, merchant dashboard,
and SEZA Admin portal.

Included:
- Cashier navigation now includes Refunds and Time Clock while sensitive actions still require manager approval.
- Cashiers cannot change protected employee PIN/account settings.
- Reliable clock-in, break, clock-out, register open/close, and shift-close recovery.
- Offline cached sign-in for the last authenticated register employee.
- Offline cash sales, drawer movements, payouts, safe drops, register open/close, and ordered sync after reconnection.
- Email and SMS receipts queue offline and deliver when authenticated connectivity returns.
- Merchant live support access from Android POS and owner dashboard.
- Admin support cases are clickable, claimable, replyable, resolvable, closable, and compatible with older database schemas.
- Support chat persists as a floating conversation while Admin navigates between pages.
- Android screen sharing stays mounted across POS navigation and Admin viewer remains compact until video arrives.
- Whole-interface language runtime improved for English, Spanish, French, Haitian Creole,
  Portuguese, Arabic, and Hebrew, including dynamic POS/Admin/support text.
- App version and Android build metadata updated.

Install after copying the update into the existing project:
  npm install --legacy-peer-deps
  npm run build
  npm run android:build
  npx cap sync android

Then commit and push:
  git add .
  git commit -m "SEZA POS reliability update 1.2.2"
  git pull --rebase origin main
  git push origin main

Important testing before production rollout:
- Build and install the APK on a real Android register.
- Test offline login, cash sale, drawer action, shift close, app restart, and reconnect sync.
- Test email/SMS using the configured live providers.
- Test screen sharing between the real Android device and Admin on a separate network.
